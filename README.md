# 从句子开始 · 英语语法地图

中文初学者语法手册，6 章、30 个主题，每节包含中文解释、结构、中英例句、易错提醒、选择题和造句草稿。无构建依赖，静态文件在 `dist/`。

## 本地打开

在此目录运行 `python -m http.server 4173 --directory dist`，然后访问 http://localhost:4173 。也可直接打开 dist/index.html。

## 数据

已读、收藏和草稿保存在浏览器 localStorage，不跨设备同步。不接入 AI，无 API 密钥，无服务器数据存储。

## 内容

课程数据在 dist/lessons.js，视图及交互在 dist/app.js，样式在 dist/style.css。讲解与例句是面向初学者的原创入门内容，非穷尽性参考语法。
