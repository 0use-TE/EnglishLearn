# 从句子开始 · 英语读写

中文初学者语法手册，6 章、32 个主题，每节包含中文解释、结构、中英例句、易错提醒、每节 4 道练习及造句草稿。无构建依赖，静态文件在 `dist/`。句子基础章包含及物／不及物动词和双宾语常用搭配。

在线访问：[英语语法地图](https://0use.net/EnglishLearn/)

语法板块提供可缩放、拖动、搜索和全屏查看的详细语法导图，包含 8 个领域、209 个知识点，支持折叠、分支聚焦、节点解释和相关课程跳转；共 128 道练习，包含逐题解析、结果统计和错题重练。例句直接展示语法拆解。按需为 13 节易混内容添加成对用法对比；情态动词另有能力、许可、建议、义务与推测对照。课程按知识点安排内容顺序：be、过去时、疑问句、不定式等采用各自的讲解段落，易混点放在基础内容之后。

章节侧栏可展开到具体课程，自动展开当前章节并标记当前课程。句子成分与修饰语章节包含地点状语、频率副词和形容词的位置说明。

## 读写训练

首页按语法、阅读、写作、词汇与表达分区，进入后仅显示该板块目录，左上角返回首页。阅读含 45 篇原创材料，每档 15 篇（基础 93～117 词、实用 168～213 词、进阶 296～425 词），覆盖权限、更新、文件操作、账户邮件、预约、退款、安装指南、API 文档、代码审查、问题报告、项目邮件、出行、订阅、方案和观点。难度标签是本站编排，不是 CEFR 测评结果。软件行为为模拟练习场景。

每篇含参考译文、3 道理解题、5 个可收藏表达，以及相关英文写作任务，共 135 道理解题、225 条表达、45 个写作任务。目录支持难度与关键词组合筛选；侧栏按难度折叠，阅读和写作均可顺序切换同难度的上一篇／下一篇。参考译文和范文默认收起。写作分别保存初稿、外部反馈与修改稿，可复制纠错提示词到外部 AI；本站不提供自动语义评分，不连接 API。词汇支持中文提示下的英文拼写核对。统一复习本自动收集语法、阅读选择题和拼写错误，也接受手动记录理解与表达问题。

首页可导出或合并导入 JSON 备份，包含语法进度、造句、读写草稿、词汇和复习记录。导入时同名读写草稿和复习记录采用备份值，集合记录合并；原有语法造句草稿保留。

## 部署

推送到 `main` 后，GitHub Actions 自动将 `dist/` 部署到 GitHub Pages。也可以在 Actions 中手动运行 `Deploy GitHub Pages`。无需安装依赖或配置密钥。

## 本地打开

在此目录运行 `python preview.py`，然后访问 http://127.0.0.1:4173/ 。此预览禁用缓存，修改后刷新即可看到更新。

发布前运行 `node scripts/version-assets.mjs`，按文件内容给 JS/CSS 链接加版本号，避免浏览器复用旧资源。线上 HTML 仍可能受托管平台缓存影响，首次切换时可用 Ctrl+Shift+R 强制刷新。

## 数据

已读、收藏和草稿保存在浏览器 localStorage，不跨设备同步。不接入 AI，无 API 密钥，无服务器数据存储。

## 内容

导图数据在 dist/atlas-data.js，交互在 dist/atlas.js。课程数据在 dist/lessons.js，补充题目在 dist/exercises.js，对比讲解在 dist/comparisons.js，答题交互在 dist/practice.js，页面在 dist/app.js，样式在 dist/style.css。讲解与例句是面向初学者的原创入门内容，非穷尽性参考语法。

阅读数据在 `dist/study-data.js`、`dist/study-advanced.js` 及 `dist/reading-*.js`，读写界面与本地存储在 `dist/study.js`，样式在 `dist/study.css`。增添阅读条目使用 `U(...)` 注册；每条同时配置段落、中文参考、表达、理解题和写作任务。

运行 `node scripts/check-reading-data.mjs` 可校验页面实际加载的数据文件、唯一 ID、难度篇幅、完整译文、选项及答案、表达上下文和范文字数。新增文章继续使用唯一 ID，避免影响已有草稿与复习记录。

## 词汇与搭配

常用词库含 1100 个单词、300 个搭配与表达，按句子基础、常用动作、人物、居家饮食、出行、学习、描述、操作、时间世界以及软件与文档等 13 个场景分类，分为基础必会、常用场景两档；这是实用编排，不是语料频率排名。每条有简短释义、原创例句和译文，重点条目附用法提醒；单词与搭配可相互跳转。常用词库与阅读收藏共用收藏和统一复习记录。

词表直接显示词卡：独立词性标记、释义、例句与译文，每页 20 条。顶部保留搜索、场景和会／不会／全部切换，可只看收藏；默认只看不会的词。卡片可直接标记会／不会和收藏，误标可撤销。原有已会状态、收藏、造句及备份记录继续使用。已移除类别、层级筛选和单独的卡片背诵模式。用法、关联搭配与造句收在卡片的补充区域。

数据在 `dist/vocabulary-data.js` 和页面按顺序加载的 `dist/vocabulary-*.js` 内容文件中，交互在 `dist/vocabulary.js`，样式在 `dist/vocabulary.css`。运行 `node scripts/check-vocabulary-data.mjs` 检查条目 ID、数量、类别、例句和译文完整性。
