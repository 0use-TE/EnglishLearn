# 从句子开始 · 英语语法地图

中文初学者语法手册，6 章、32 个主题，每节包含中文解释、结构、中英例句、易错提醒、每节 4 道练习及造句草稿。无构建依赖，静态文件在 `dist/`。句子基础章包含及物／不及物动词和双宾语常用搭配。

在线访问：[英语语法地图](https://0use.net/EnglishLearn/)

首页提供可缩放、拖动、搜索和全屏查看的详细语法导图，包含 8 个领域、209 个知识点，支持折叠、分支聚焦、节点解释和相关课程跳转；共 128 道练习，包含逐题解析、结果统计和错题重练。例句直接展示语法拆解。按需为 13 节易混内容添加成对用法对比；情态动词另有能力、许可、建议、义务与推测对照。课程按知识点安排内容顺序：be、过去时、疑问句、不定式等采用各自的讲解段落，易混点放在基础内容之后。

章节侧栏可展开到具体课程，自动展开当前章节并标记当前课程。句子成分与修饰语章节包含地点状语、频率副词和形容词的位置说明。

## 部署

推送到 `main` 后，GitHub Actions 自动将 `dist/` 部署到 GitHub Pages。也可以在 Actions 中手动运行 `Deploy GitHub Pages`。无需安装依赖或配置密钥。

## 本地打开

在此目录运行 `python preview.py`，然后访问 http://127.0.0.1:4173/ 。此预览禁用缓存，修改后刷新即可看到更新。

发布前运行 `node scripts/version-assets.mjs`，按文件内容给 JS/CSS 链接加版本号，避免浏览器复用旧资源。线上 HTML 仍可能受托管平台缓存影响，首次切换时可用 Ctrl+Shift+R 强制刷新。

## 数据

已读、收藏和草稿保存在浏览器 localStorage，不跨设备同步。不接入 AI，无 API 密钥，无服务器数据存储。

## 内容

导图数据在 dist/atlas-data.js，交互在 dist/atlas.js。课程数据在 dist/lessons.js，补充题目在 dist/exercises.js，对比讲解在 dist/comparisons.js，答题交互在 dist/practice.js，页面在 dist/app.js，样式在 dist/style.css。讲解与例句是面向初学者的原创入门内容，非穷尽性参考语法。
